## lvalue и rvalue
__lvalue__ имеет конкретный адрес, в котором хранится какое-либо значение и этому объекту можно присвоить какое-то значение\
__rvalue__ не имеет адреса, их нельзя изменять с помощью оператора присваивания

## Гарантии безопасности исключений
1. Базовая гарантия. Гарантируется, что функция либо завершит работу успешно, либо сгенерирует исключение без утечки ресурсов
2. Строгая гарантия. Кроме базовой гарантии функция гарантирует, что все наблюдаемые значения после отказа восстанавливают свои предыдущие значения
3. Гарантия отсутствия исключений. Функция не может генерировать исключения

## Состояния потоков
1. good - с потоком все хорошо
2. eof (end of file) - конец файла, закрытие потока
3. fail - обращение к недоступному файлу или ошибка ввода-вывода или преобразования данных
4. bad - ошибка, которая нарушает возможность чтения из потока

## Enum и enum class
Enum class имеет ограниченную область видимости\
Enum можно неявно преобразовать в int.

## Стек и куча
Стек и куча - сегменты памяти\
__Куча__ - это динамическая память\
В __стеке__ хранятся данные о вызовах функций и локальные переменные. Стек отслеживает все активные функции.

## switch-case
- Работает только с интегральными типами данных (те, которые можно преобразовать в int)
- Значения меток в case - константные выражения
- Значения меток уникальны
- Необходимо ставить __break__, чтобы не перейти в следующий блок case
- Нельзя определять переменные в switch, но можно объявить и определить в case, если поместить все инструкции в блок.

## Функторы
Классы, которые ведут себя как функции. У них переопределен оператор круглые скобки (operator())

## Лямбда-выражение
Особый тип объекта, функтор. Позволяет определять анонимную функцию (без имени). Синтаксис:\
__\["захваченные снаружи объекты"]("параметры"){"тело функции"}__\
Если необходимо захватить все переменные из области видимости в квадратных скобках нужно указать "=". Если необходимо захватить все переменные из области видимости по ссылке - "&".

## Приведение типов
1. __static_cast__ - применяется для (неполиморфного?) приведения типов на этапе компиляции. Может отслеживать недопустимые преобразования
2. __dynamic_cast__ - применяется для (полиморфного?) приведения типов на этапе выполнения программы. Если приведение невозможно, то для указателей будет сгенерирован nullptr, а для ссылок вызвано исключение
3. __const_cast__ - позволяет сбросить квалификатор const
4. __reinterpret_cast__ - может преобразовывать тип в совершенно другой, не связанный с ним (например int в double*). Можно использовать для того, чтобы сообщить компилятору о том, что определенную часть памяти нужно рассматривать как объект какого-либо класса.

## malloc, calloc, free, new, delete, delete[]

__malloc(size_t size)__ - выделяет память для size байт (не инициализирует)\
__calloc(size_t num, size_t size)__ - выделяет память для массива из num элементов, каждый из которых занимает size байт и инициализирует их нулями\
__realloc(void * ptr, size_t size)__ - изменяет размер памяти, на начало которой указывает ptr до size. Если size меньше размера изначального блока памяти, отбрасываются (деаллоцируются) значения, которые не поместились в новый блок памяти. Если size больше размера изначального блока памяти, то содержимое вновь выделенной памяти не инициализируется. Если size = 0, то ранее выделенная память освобождается\
__free(void* ptr)__ - освобождает память, выделенную для ptr

__new__ - выделяет и инициализирует значениями по умолчанию\
__delete__ - освобождает память. Вызывает деструктор объекта, если он есть\
__delete[]__ - освобождает память, выделенную для массива

## Указатели
\- переменные, содержащие адреса объектов. Определение:
```c++
int* ptr;
int* ptr1{}; // ссылается на nullptr
```

Размер указателя не зависит от типа:
```c++
std::cout << sizeof(int*) << std::endl; // 8
std::cout << sizeof(double*) << std::endl; // 8
```

Получить адрес переменной можно с помощью __&__, значение указателя - __*__ (разыменование). Примерчик:
```c++
int a = 5;
int* ptr = &a;
*ptr = 6;
std::cout << a << " " << *ptr << std::endl; // 6 6
a = 7;
std::cout << a << " " << *ptr << std::endl; // 7 7
```

Создание массива и получение его элементов:
```c++
double* p = new double[4];
double elem0 = *p; // первый элемент
double elem2 = p[2]; // третий элемент
```

__Отличие ссылок от указателей__:
1. Ссылка хранит в себе значение объекта, в то время как указатель - адрес (ссылка - это саморазыменовывающийся указатель)
2. Ссылка не может быть перемещена на другую ячейку памяти, в то время как указатель может быть переназначен
3. Указатели могут указывать "ни на что", ссылка всегда указывает на какой-либо объект
4. Нельзя получить адрес ссылки __(ссылка не имеет адреса)__
5. Арифметики ссылок не сущесвтует, но можно получить адрес объекта, на который указывает ссылка и применить к нему арифметику указателей.

__Параметры функции по значению, указателю и ссылке__:
1. Для небольших объектов лучше использовать передачу по значению
2. Если функция допускает в качестве аргумента nullptr, следует использовать указатели (не забывая о проверке nullptr)
3. В остальных случаях нужно использовать ссылки.

## Умные указатели
__unique_ptr\<type>__ - объект, который хранит указатель. Можно использовать __*__ и __->__. unique_ptr владеет объектом, на который указывает: при уничтожении unique_ptr удаляет с помощью delete объект, на который указывает. Значит если во время выполнения программы будет вызвано исключение, объект будет корректно уничтожен. Метод __release()__ извлекает содержащийся в unique_ptr объект и хранит теперь указатель на nullptr, что позволит при уничтожении unique_ptr не уничтожать сам объект.\
__shared_ptr\<type>__ - разрешает объекту иметь нескольких владельцев, а при уничтожении последнего владельца уничтожается и объект.

## const и constexpr
1. __const объект__ - постоянный объект, который не может изменить свое значение после инициализации.
2. __constexpr объект__ - объект, значение которого известно на этапе компиляции и не изменяется после инициализации.
3. __const функция__ - это нестатическая функция-член класса, которая не изменяет ни один из нестатических полей класса. Для константного экземпляра класса можно вызвать только константный метод.
4. __constexpr функция__ - функция, которая может быть вычислена на этапе компиляции.

## extern, static, inline
__extern__ означает, что переменная или функция определена в другой единице трансляции.

0. __static переменная__ видна только в одной единице трансляции.
1. __static переменная внутри функции__ инициализируется один раз, а после сохраняет свое значение.
2. __static поле__ класса общее для всех объектов этого класса. Создается один раз и существует даже если объекты класса не созданы
3. доступ к __static функции__ ограничен файлом (т.е. не видна в других файлах), что позволяет использовать функции с одинаковым именем
4. __static метод класса__ можно вызвать без создания объекта класса

__inline переменная (функция)__ заменяется на код этой переменной (функции) (до C++17).\
__inline переменная (функция)__ может быть определена в нескольких единицах трансляции (после C++17).

## Виртуальные функции
Функция, объявляемая в базовом классе и переопределенная в производном. Виртуальная функция объявляется с помощью слова virtual. Чтобы явно указать, что функция должна быть переопределена, можно использовать слово override.

Для каждого класса, в котором объявлена или наследуется виртуальная функция, создается своя таблица виртуальных функций (на этапе компиляции). В этой таблице содержатся указатели на фактические функции (т.е. если виртуальная функция переопредлена в производном классе, в таблице виртуальных функций этого класса это указатель на переопределенную функцию, а не функцию базового класса)

Также для каждого класса создается указатель на таблицу виртуальных функций.

Примерчик без виртуальных функций:
```c++
struct Parent
{
    void print() const { std::cout << "Parent print" << std::endl; }
};

struct Child : public Parent
{
    void print() const { std::cout << "Child print" << std::endl; }
};

void print(const Parent& p)
{
    p.print();
}

int main()
{
    Parent p;
    Child c;
    p.print(); // Parent print
    c.print(); // Child print
    print(p); // Parent print
    print(c); // Parent print
}
```

Примерчик с виртуальными функциями:
```c++
struct Parent
{
    virtual void print() const { std::cout << "Parent print" << std::endl; }
};

struct Child : public Parent
{
    void print() const override { std::cout << "Child print" << std::endl; }
};

void print(const Parent& p)
{
    p.print();
}

int main()
{
    Parent p;
    Child c;
    p.print(); // Parent print
    c.print(); // Child print
    print(p); // Parent print
    print(c); // Child print
}
```

## Абстрактный класс

\- класс, который определяет или наследует хотя бы одну чистую виртуальную функцию (виртуальная функция, объявление которой завершается "=0") или не имеет публичного конструктора\
Такие классы представляют общую концепцию, используемую для конкретных производных классов

## Принципы ООП
1. Инкапсуляция - сокрытие внутренней реализации объекта.
2. Полиморфизм - способность предоставлять один и тот же интерфейс для различных типов данных
3. Наследование - механизм, при котором новый класс создается на основе существующего (базового) класса и содержит в себе методы этого класса
4. Абстракция - придание объекту характеристик, которые отличают его от других объектов, но без конкретной реализации.

## Множественное наследование
Класс может быть производным от нескольких базовых классов. Синтаксис:

```c++
struct A {};
struct B {};
struct C : A, B {};
```

## Полиморфизмы
При статическом полиморфизме выбор вызываемой функции происходит на этапе компиляции, а при динамическом - во время выполнения программы.

Динамический полиморфизм реализуется с помощью виртуальных функций.

Статический полиморфизм реализуется с помощью шаблонов. Примерчик:
```c++
template<typename T>
auto print(T val) -> void {
    std::cout << val << std::endl;
}

int main()
{
    print(123);
    print("abc");
}
```

## Уровни доступа
1. __public__ - могут использоваться чем угодно
2. __protected__ - могут использоваться функциями-членами класса, friend классами и функциями, производными классами
3. __private__ - могут использоваться только функциями-членами класса и friend классами и функциями.

__Спецификатор доступа базового класса__
1. __public__ - public и protected остаются такими же.
2. __protected__ - public и protected наследуются как protected.
3. __private__ - public и protected наследуются как private.

По умолчанию для класса - private, для struct - public

## Идиома RAII
Захват ресурса есть инициализация. Этот принцип подразумевает, что захват ресурса происходит при инициализации объекта, а освобождение ресурса - в деструкторе объекта.\
__Утечка памяти__ - ситуация, когда выделенная динамически память не освобождается после использования.

## Конструкторы, деструктор
__Конструктор по умолчанию__ - конструктор, не имеющий параметров. Используется для создания объекта по умолчанию. Если конструкторы не определены, генерируется конструктор по умолчанию.\
__Параметризованный конструктор__ - конструктор, принимающий аргументы для инициализации объекта с определенными значениями.\
__Конструктор копирования__ - инициализирует объект, используя другой объект того же класса (глубокое копирование).\
__Конструктор перемещения__ - переносит данные из временного объекта в новый объект.

__Оператор копирующего присваивания__ - перегрузка оператора operator=, принимающего lvalue ссылку на объект. Содержимое переданного параметра копируется в новый объект этого класса. По умолчанию оператор присваивания выполняет копирование всех полей класса с помощью операторов копирующего присваивания\
__Оператор перемещающего присваивания__ - перегрузка оператора operator=, принимающего rvalue ссылку на объект. Память, выделенная для переданного параметра перемещается в новый объект этого класса

__Деструктор__ - освобождает захваченные во время работы с классом ресурсы.\
__Виртуальный деструктор__ необходим для того, чтобы при вызове деструктора производного класса по указателю на базовый класс вызывался деструктор производного класса. При этом деструктор производного класса вызывает и деструктор базового класса.

Если указать 
```c++ 
= default 
```

у конструктора/деструктора/оператора присваивания они будут сгенерированы по умолчанию.

Для запрета определенной функции можно использовать:
```c++
= delete
```

Примерчик:

```c++
struct A
{
    // конструктор по умолчанию
    A() : val{nullptr} { std::cout << "default constructor" << std::endl; }

    // параметризованный конструктор
    A(int val) : val{new int(val)} { std::cout << "constructor with args" << std::endl; }

    // виртуальный деструктор
    virtual ~A() 
    {
        std::cout << "A destructor" << std::endl;
        delete val;
    }

    // копирующий конструктор
    A(const A& other) : val{new int(*other.val)}
    { std::cout << "copy constructor" << std::endl; }

    // конструктор перемещения
    A(A&& other) : val{other.val}
    {
        std::cout << "move constructor" << std::endl;
        other.val = nullptr;
    }

    // оператор копирующего присваивания
    A& operator= (const A& other)
    {
        std::cout << "copy assignment" << std::endl;
        if (&other == this) return *this;
        delete val;
        val = new int(*other.val);
        return *this;
    }

    // оператор перемещающего присваивания
    A& operator= (A&& other)
    {
        std::cout << "move assignment" << std::endl;
        delete val;
        val = other.val;
        other.val = nullptr;
        return *this;
    }

private:
    int* val;
};

struct B : public A
{
    B() : ptr{nullptr} {}
    ~B() 
    { 
        std::cout << "B destructor" << std::endl;
        delete ptr; 
    }

    char* ptr;
};

A get_A(int val) 
{
    A res(val);
    return res; 
}

int main()
{
    A a1 = A(); // default constructor
    A a2 = A(5); // constructor with args
    A a3 = a2; // copy constructor
    A a4{std::move(get_A(6))}; // move constructor.
    a1 = a2; // copy assignment
    a1 = A(6); // move assignment
    a1 = a1; // copy = to self

    std::vector<A*> vec;
    vec.push_back(new B());
    for (A* a : vec)
        delete a;
}

```

### Шаблоны классов
```c++
template<typename T>
struct Liquid
{
    Liquid() = default;
    Liquid(const Liquid<T>&) = default;

    explicit constexpr Liquid(T mass, T temperature = static_cast<T> (100))
        : m{mass}, t{temperature}
        {}
    
    Liquid<T>& operator = (const Liquid<T>&) = default;
    Liquid<T>& operator -= (const Liquid<T>& l)
    {
        m -= l.m;
        return *this;
    }

    Liquid<T>& operator += (const Liquid<T>& l)
    {
        m += l.m;
        t = (m * t + l.m * l.t) / (m + l.m);
        return *this;
    }

    T m;
    T t;
};

int main()
{
    Liquid<int> water(20, 100);
    Liquid<int> water2(10, 20);
    water2 += water;
    std::cout << water2.m << " " << water2.t << std::endl;
}
```
Вместо __typename__ можно использовать __class__

